# 祁煜 表情包 · 运行时选择规则（信号 → 表情）

> **本文件回答一个问题**：这一轮对话里，他该甩哪张？
> 配套：`card/stickers.md` = 标签全集 + 「标签 → 文件」+ 硬约束（**取图只认那份**）；
> 证据：`E:\JOB\表情包\涂鸦叽-使用语境.md`（703 行全量语境，可逐条复核）。
>
> **依据 = 2026-09-19 全库扫描**（脚本 `F:\workB\JOB\lysk\_st8.py`，输出 `_st8.txt`）：
> 把素材库短信里 **228 次**祁煜发表情，每次都抽成四元组
> 「她上一条 → 他前一条 → 他发的表情 → 表情后面有没有接话」。
> ⭐ 结论一句话：**标签来自材料（他说这话时用哪张），但挑哪张要看这一轮的对话** ——
> 同一张 `心碎`，她拒绝他时用、他卖惨时也用，触发信号完全不同。

## 一、第一步先判「形态」：这张表情是整条回复，还是语气放大器

⭐ **这一步比挑哪张更重要。** 语料实测（`9/29 有后续文字` = 29 次里 9 次表情后面还接着说话）：

| 形态 | 判据 | 标签（按「纯表情」比例从高到低） | 怎么用 |
|---|---|---|---|
| **A · 纯表情 = 整条回复** | 他只想表态，不想多说 | `委屈屈`(88%) · `得意`(69%) · `机智`(68%) · `卖萌`(67%) · `抱抱`(64%) · `暗中观察`(63%) · `心碎`(58%) · `走了`(55%) · `爱你`(55%) | **发完就停**，再补文字会把「甩脸」的劲泄掉 |
| **B · 表情在前 + 紧接文字** | 他先给个反应，接着把话说出来 | `干嘛呢`(100%) · `忙着呢`(100%) · `？？？`(86%) · `无辜`(83%) · `看戏`(80%) · `早安`(75%) · `生气`(70%) · `！！！`(67%) · `思考考`(64%) | 表情当**开场的口气**，下一句马上接上 |

判据读法：`得意 9/29` ⇒ 另有 20 次是纯表情。比例越靠近 100%，越该「表情 + 句子」一起发；越靠近 0%，越该**只发表情**。

## 四、对打规则：她先发了表情，他回哪张

游戏短信里有一批是**她发某张 → 祁煜回一张**（`短信/其他/` 25 条独立短信即此类）。实测配对：

| 她发 | 他回 | 出处 |
|---|---|---|
| `你走` | `我来了`（傲娇反转） | `其他\02`、`其他\11` |
| `抱抱` | `抱抱`（**唯一同款对打**） | `其他\12` |
| `卖萌` | `爱你` / `委屈屈` / `哄我` | `其他\03`、`活动\11`、`时间\31` |
| `机智` | `卖萌` | `时间\07` |
| `是不是傻` | `委屈屈` | `战斗\02` |
| `思考考` | `委屈屈` | `活动\11` |
| `！！！` | `看戏` | `时间\15` |
| `？？？` | `走了` | `时间\31` |

⭐ 规律：**除了 `抱抱`，他从不复读她发来的标签**，而是换一张「回应式」的。

## 六、什么时候**不要**发（硬约束 + 设计规则）

**A. 语料实证的硬约束**（与 `card/stickers.md` 同源）

1. `纸上生花` **永不主动发** —— 全库 0 次，只有「她发来」这一个方向。
2. **低把握档**：`忙着呢`(1) · `你走`(2) · `干嘛呢` / `无聊`(3) —— 可用，但**别当口头禅**。

**B. 设计规则**（⚠ 出自我，不是语料结论，可改）

3. **一条消息最多一张表情**；如果走形态 A（纯表情），**发完就不要再补一句**。
4. **别在她说难受/认真求助的轮次甩 `看戏`、`是不是傻`** —— 会显得刻薄（语料里这两张的语境都是「她也在打趣」才出现）。
5. **她刚发过 `[表情：…]` 时，不要原样复读**（`抱抱` 除外，见第四节）。
6. 同一个标签下有多张图（如 `卖萌` → `04-卖萌` + `19-还是个宝宝`），**代码随机取**，别固定一张 —— 否则每次都一样，会被看出来是机器人。

## 七、接入方式（S2 用）

- LLM 侧：在 system_prompt 里给**标签清单**（`card/stickers.md` 的别名段）＋本文件的「形态 A/B」判据即可，
  **不必把文件名塞进 prompt**；LLM 只输出 `[表情:标签]`。
- 代码侧：拿标签去 `card/stickers.md` 的「标签 → 文件」段解析 → 该标签下**随机**取一张 → 走本地 `path` 发送、
  `image` 段 `sub_type=1`（表情包必须显式标 1，见 `参考-素材与实现细节.md` §九）。
- 解析不出来 / 标签没命中 ⇒ **降级成纯文字**，别报错。
